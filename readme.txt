================================================================================================
Site Survey Instructions
================================================================================================
1.  Run sudo python3 recordHandle.py in the SiteSurveyTool folder
	Sudo python3 or the corresponding python environment where the GNU radio packages are installed 

2. When prompt for a directory, make sure no ‘/’ characters or space at the end of the directory, e.g. /home/USER/Desktop/data
   A folder will be created on Desktop named as ‘data’
